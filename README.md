# Prompt-dog / Skill Architect（终极技能架构师）

一个「设计提示词的提示词专家」Agent Skill：把模糊需求变成可被证明有效的提示词、SOP 或完整 Agent 工作流。

## 解决什么问题

普通用户面对 AI 最大的障碍不是不会用，而是**说不清需求**——尤其是行业 know-how 和工作流程。传统做法（AI 连续开放式提问）把表述负担丢回给用户；本技能反过来：

- **提案代替提问**：所有澄清都是带推荐默认值（★）的选择题，用户最少回一句「都按推荐」即可放行；行业常见做法由技能先给候选、用户挑选修正。
- **复杂度自适应**：六信号量表自动判级——简单任务直接给优化提示词（L1），中等给步骤化 SOP（L2），复杂给提示链设计（L3）或多智能体编排（L4，含子 agent 分配、所需 skill 与工具清单）。能简单绝不复杂。
- **验证内置**：准确性要求高的任务，验收标准先于设计确认，按错误代价配置验证机制（自我一致性/交叉核查/来源强制/对抗审查/人工确认点）。
- **闭环有终点**：复杂任务内嵌「执行→评估→诊断→精调」循环，终止条件写死，绝不空转。

## 文件结构

```
skill-architect/
├── SKILL.md                        主流程与决策规则（判级量表、问题预算、铁律）
├── references/
│   ├── clarify-cards.md            确认卡片模板、回复解析表、行业候选库
│   ├── complexity-routing.md       六信号打分锚点、级别路由表、信号→策略速查表
│   ├── strategy-map.md             提示词策略全量档案与组合建议
│   ├── output-templates.md         L1–L4 产物模板（提示词/SOP/提示链/多智能体编排）
│   ├── verification.md             验收标准卡、验证机制选型、诊断分支表、终止条件、自检清单
│   └── diagnose.md                 现有提示词诊断改进（十维评分，低摩擦两步流程）
└── evals/
    └── evals.json                  测试用例（含不应触发的负例）
```

## 使用

在支持 Agent Skill 的环境中安装本目录后，对 Agent 说：

- 「帮我写一个 XX 提示词」→ 得到优化提示词
- 「帮我看看这个提示词写得怎么样：……」→ 得到十维评分 + 改进版
- 「帮我设计一个每周自动 XX 的工作流」→ 得到完整流程设计（提示链/子 agent/验证/循环）

设计理念源自五阶段提示词工程流程（规划架构 → 基础构建 → 执行评估 → 诊断精调 → 工程化管理）与提示词策略分类体系。
