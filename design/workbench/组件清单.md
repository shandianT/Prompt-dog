# 组件清单：设计组件 → 开发组件 v0.1（2026-09-08）

> 画布「组件」页每个组件一张画板列全部状态；这份把每个组件的 **props · 状态 · 用在哪些屏 · 用什么开源件承接 · 设计源在哪个函数** 写成表。规则只有三条：① 屏幕只能由这里列出的组件拼装，屏幕文件里不允许出现组件之外的样式；② 一屏只有一个主按钮；③ 组件的 token 来自 SPEC §7，不在组件里硬编码颜色。技术栈按 `开源选型.md`：React + TypeScript + Vite · shadcn/ui（Radix）· `@xyflow/react` v12 · Tremor。

## 两层组件

| 层 | 是什么 | 在画布上 | 开发对应 |
|---|---|---|---|
| 真组件 | 可传参，屏幕通过 `<dc-import>` 引用，改一处所有屏跟着变 | `Sidebar.dc.html` · `Topbar.dc.html` · `InputBar.dc.html` · `FlowNode.dc.html`，属性面板可切变体 | 同名 React 组件，props 一一对应 |
| 状态表 | 每个组件一张画板列全部状态；每一块由生成屏幕的同一个 Python 函数产出，屏幕与组件表不会漂移 | `Comp*.dc.html` 12 张 + `Components.dc.html`（token 与基础件） | 一个组件 = 一个文件夹（`index.tsx` + `*.stories.tsx`），状态表就是 Storybook 的故事清单 |

设计源统一在 `design/workbench/*.py`：改 Python 函数 → `python3 flow.py` → 屏幕和组件表同时更新。

## 开发约定

1. 目录：`src/components/<Name>/index.tsx` + `<Name>.stories.tsx`，故事名 = 画布状态表里的状态名（如 `StagesPanel/停机行`）。
2. props 与本表一致，枚举值照抄（`kind`、`state`、`flag` 的取值不改名）；所有颜色通过 SPEC §7 的 token。
3. 一屏一个 `primary` 动作；`Topbar.actions` 最多两个。
4. 画布三件（`FlowNode` / `FlowEdge` / `FlowLanes`）挂在 React Flow 的 `nodeTypes / edgeTypes` 上，数据结构就是 `flow.schema.json`。
5. 状态来源：`验收清单.json` → StagesPanel · DogCard.status · RunRow · FlowNode.rb；flow JSON → FiveNumbers · DiagCard · PreviewCard(用于 N 条流程)。
