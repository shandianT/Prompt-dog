# 使用说明

## 两种上岗方式

- **当 Skill 装**（Codex/Claude Code/支持 Agent Skill 的环境）：整个文件夹放进技能目录即可，根目录 SKILL.md 就是入口
- **当工作狗用**（WorkBuddy/工作区型 Agent）：文件夹拖进工作区，从 启动指令.md 复制指令发送

## 先喂素材库（重要）

`素材库/` 是这只犬的口粮：把你的真实数字（收入/价格/案例数据）、真实案例（人+结果）、个人金句和经历片段各建一个 md 丢进去。**素材库越厚，文案越像你本人**——这是「人格不可外包」的工程化解法。

## 日常三个动作

1. 写作：从 启动指令.md 复制指令（选择题确认后直接出稿）
2. 复盘（每周）：说「复盘」——数据回填，新金句入库
3. 改版跑回归：修改 prompts/ 后说「跑回归」，对照你的历史爆款检查

## 红线提醒

它绝不编数字和案例——缺素材会输出【待填真实数字】占位。发布前把占位全部替换，这是你的最后一道人工确认。
