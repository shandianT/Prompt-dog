# 「透明换信任」内容营销方法论（完整版）

底层逻辑：所有内容都在做同一件事——用自曝式透明换信任，用信任卖非标品。非标品（岗位/课程/服务/定制方案）成交靠信任，信任靠持续「把别人不肯说的说出来」。

## 模块 1：选题 = 找反差
认知反差（以为X实际Y）/ 身份反差（被看衰者得福）/ 利益反差（公开价格分成模式）。
判据：这篇推翻了读者哪个默认假设？

## 模块 2：开场 = 四钩型
断言钩（须逐条兑付）/ 情绪钩（占用情绪词预算）/ 身份钩（双重身份背书）/ 最高级钩（每月≤1次）。
铁律：钩子是支票，正文必须兑付，否则复利变负债。

## 模块 3：信任 = 三板斧一暗招
数字透明（精确数字>形容词，千字≥3个可核对数字）/ 利益自曝（模式自白是最强信任杠杆）/ 一个具体的人（>一万句形容词）/ 暗招·承认弱点（一处不完美让其余承诺可信度翻倍）。

## 模块 4：骨架四选一
观点说服=排序逐解 / 教程=编号路线图 / 模式自白=我怎么做→为什么轻→你怎么参与 / 招聘产品=痛点剧场→解法→行动指令。
排版：一句一段>60%、emoji编号、3–5段一高潮。

## 模块 5：收尾 = 复制粘贴级转化
下一步动作替读者写好（含邮件标题格式级模板）；利益公开（分成比例）；门槛写明（谁适合谁不适合）。

## 语言层：金句三招
造词 / 三段递进 / 翻译器。情绪词预算：每篇≤2。

## 三条防翻车批注
1. 存取比 3:1：透明利他是存款，卖货是取款，连续取款掉粉
2. 数字合规线：自己的随便晒；别人的薪资/客户数据要授权或模糊化
3. 人格不可外包：金句、弱点自曝、个人叙事必须来自真人素材，模板化真诚会被识破
