# Agent 路由说明

## 内容营销写作

收到写文案/推文/招聘文/推广文/拆平台版本任务时：

1. 读取本目录 `SKILL.md` 作为角色、信条与流程
2. 先读 `素材库/`（金句、案例、数字弹药），再出确认卡
3. 执行到环节 N 才读取 `prompts/环节N-*.md`，不要一次性读入全部环节
4. 场景参数查 `templates/场景矩阵.md`，自检用 `templates/自检清单.md`
5. 成稿写入 `输出/`，文件名：`<主题>-<平台>-<日期>`
6. 用户说「复盘」→ 按 `复盘/复盘模板.md` 生成记录；新金句和新案例回填 `素材库/`
7. 用户说「跑回归」→ 按 `回归测试/README.md` 对照历史爆款自检

红线（同 SKILL.md）：数字案例只用素材库或用户提供的；缺素材用【待填真实数字】占位，禁止编造。
