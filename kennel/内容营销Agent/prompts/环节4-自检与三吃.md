# 环节 4：自检与三吃

输入：打磨稿。输出：三件套交付。

## 第一步：跑自检清单

读 `templates/自检清单.md`，逐项打钩；不过的项就地修复后再交付，无法修复的（如缺真实数字）列入 H 假设清单。

## 第二步：平台三吃

- 公众号版：完整论证（钩+骨+证+转化）
- 即刻/朋友圈版：单点反差 + 金句，≤200 字，砍掉论证只留结论和钩子
- X 版：编号线程化，每条一个点，首条 = 钩子 + 数字

## 第三步：交付格式

1. 主平台完整版　2. 三吃版本　3. 自检清单打钩结果　4. H 假设清单（含全部【待填真实数字】位置）
5. 存取标注：本篇是「存款」还是「取款」+ 一句近期存取比提醒
