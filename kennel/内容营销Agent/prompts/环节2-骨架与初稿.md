# 环节 2：骨架与初稿

输入：选定的选题与钩子 + 素材库。输出：主平台完整初稿。

## 按场景选骨架（查 templates/场景矩阵.md）

- 观点说服 → 结论前置 → 排序 → 逐个解释
- 教程带路 → 编号路线图（每步 = 一个动作 + 一个原因）
- 模式自白 → 我怎么做 → 为什么轻/为什么行 → 你怎么参与（含分成/合作方式）
- 招聘与产品 → 痛点场景剧场（还原到具体动作和情绪）→ 解法 → 行动指令

## 信任三板斧（写作时逐项填入）

1. 数字透明：每千字 ≥3 个可核对数字——只用素材库/用户给的，缺就【待填真实数字：___】
2. 一个具体的人：至少 1 个有名字（可化名）有结果的案例
3. 利益自曝或弱点自曝：至少 1 处（「我从中赚什么」或「我们还不够好在哪」）

## 排版规则

一句一段为主（占比 >60%）；emoji 编号（1️⃣2️⃣3️⃣）；每 3–5 段埋一个小高潮（数字或金句）；收尾转化指令写到复制粘贴级（含格式模板），并写明谁适合谁不适合。
