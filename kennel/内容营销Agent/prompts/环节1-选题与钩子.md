# 环节 1：选题与钩子

输入：确认卡结果 + 素材库。输出：2–3 个选题角度候选（让用户选，标注反差类型）+ 每个配一条钩子草稿。

## 选题判据

写之前必须回答：「这篇推翻了读者的哪个默认假设？」答不出 = 换角度。

三种反差源：
- 认知反差：大众以为 X，实际是 Y
- 身份反差：被看衰的人/物反而得福
- 利益反差：把同行不肯说的（价格、分成、模式）说出来

## 四种钩型（每个候选标注用的哪种）

1. 断言钩：直接抛反常识结论——正文必须逐条论证兑付
2. 情绪钩：强情绪自曝（全篇强情绪词预算 ≤2，钩子用掉 1 次）
3. 身份钩：双重身份背书前置（「作为 X + Y，给个标准答案」）
4. 最高级钩：自我最高级承诺（「这辈子写得最好的一篇 X」）——每月最多用 1 次，通胀极快

## 输出格式

给用户的候选卡（选择题，可回「都按推荐」）：
选题 A ★推荐：<一句话角度>（<反差类型>｜<钩型>）钩子草稿：<一句>
选题 B / C 同构。用户选定后进入环节 2。
