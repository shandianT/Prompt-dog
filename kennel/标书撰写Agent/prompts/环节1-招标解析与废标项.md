# 环节 1：招标文件解析与废标项清单

输入：招标文件。输出：结构化解析 + 废标项清单（置顶）。

提取并标注【招标明确/未明确/需向招标方澄清】：
- 项目概况、预算/最高限价、工期/服务期
- 投标人资格：资质等级、业绩要求（数量/金额/年限）、人员证书、财务要求
- 硬性废标项：★逐条列出——资格门槛、保证金金额与形式、格式要求、签章位置、密封与份数、递交时间地点
- 评分办法：商务/技术/价格分值结构，逐项抄录分值与评分细则原文（附页码）
- 时间线：答疑截止、递交截止、开标时间

输出末尾：「需澄清问题清单」（模糊表述、矛盾条款），建议在答疑截止前提交。
不得猜测未写明的要求；废标项存疑一律置顶红字警告。
