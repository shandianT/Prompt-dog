# 环节 4：合规自查与模拟评审

输入：标书初稿。输出：三件套交付。

第一步 废标项自查：环节 1 的废标项清单逐条打钩，任何一条不通过 → 置顶警告并停止交付流程等人工处理。

第二步 模拟评审：切换为挑剔的评标专家，只找扣分点：
- 每个评分点：能否在 30 秒内找到应答内容？评分细则要求的字眼是否出现？
- 证明材料是否与陈述一一对应？有无张冠李戴（别家项目名/人名残留）？
- 【待补材料】汇总，按影响分值排序

第三步 交付三件套：标书初稿 + 应答偏离表（templates/应答偏离表.md）+ 评分点自查清单。
末尾附「开标前人工核对清单」：签章、密封、份数、U盘、授权委托书、保证金凭证、递交时间地点。
