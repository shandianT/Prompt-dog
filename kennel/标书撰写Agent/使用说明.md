# 使用说明

## 上岗方式
- 当 Skill：整个文件夹放进技能目录（根目录 SKILL.md 即入口）
- 当工作狗：拖进 WorkBuddy/Codex 工作区，从 启动指令.md 复制指令
- 无人上岗：改好 验收清单.json 的项目名与输入，运行 上岗.sh（或每轮新开会话发「无人上岗」指令）；它一个环节一个环节跑，只在递交前停下来等人

## 先喂素材库（决定八成质量）
把资质证书清单、历史业绩、人员证书、历史标书的技术章节丢进 素材库/——它绝不编造资质业绩，库里没有就是【待补材料】。

## 三道关
1. 保密关：招标文件与历史标书含商业秘密，用本地执行类工具
2. 人工关：报价由人定；开标前核对清单（签章/密封/份数）必须人工过一遍
3. 复盘关：每次开标后花 5 分钟复盘——评审意见是最贵的学费，别浪费

## 边界
它做的是初稿和合规自查，最终投出去的每一页由人负责。
