# 使用说明（照做即可）

## 这个文件夹是什么

一个可直接使用的「商事合同风险审查 Agent」：给律师/律师助理做合同初审，输出审查报告、原文批注、结构化风险清单三件套。审查逻辑全部在 `审查流程.md` 里。

## WorkBuddy 用法（推荐先用这个）

1. 把本文件夹整个放到电脑上（例如桌面）
2. 把一份**脱敏后**的合同放进 `待审合同/`
3. 对 WorkBuddy 说（每次审查只改文件名和立场）：

> 读取 合同审查Agent/AGENTS.md 并按其规则，审查 合同审查Agent/待审合同/XX合同.pdf。
> 审查立场：甲方风险优先。委托方：XX公司。业务背景：（一句话，可不填）

4. 完成后到 `输出/` 拿三件套

## SoWork / Codex / Claude Code 用法

把本文件夹放进工作区即可——这类工具会自动读 `AGENTS.md`。之后直接说：

> 审查 待审合同/XX合同.pdf，立场：甲方风险优先

## 没有联网检索的环境

`AGENTS.md` 最后一条已写了降级规则：不编造法条，一律标【待律师核查】。无需额外配置。

## 正式启用前的三道关

1. **保密关**：测试全程用脱敏合同；确认所用平台的数据条款符合律所保密要求（本地执行类工具此项先天占优）
2. **回归关**：让律师挑 3–5 份已人工审过的历史合同跑一遍，对照当年结论数四个指标——漏审、误报、定位失败、虚构来源。**漏审和虚构来源必须为 0** 才能日常使用
3. **边界关**：告知所有使用者——这是初审底稿工具，不出最终法律意见，签字责任永远在人

## 日常三个动作（形成飞轮）

1. **审查**：从 `启动指令.md` 复制指令、改参数、发送——不要每次现编指令
2. **复盘**（每周）：说「复盘」，Agent 按四指标对照人工修改稿生成记录——漏审误报会变成提示词改进建议
3. **改版必跑回归**：任何提示词修改后说「跑回归」，漏审和虚构来源为 0 才发布（门槛见 回归测试/README.md）

用得越多，复盘沉淀越厚，这个 Agent 就越贴合你所——这是别人拷不走的部分。

## 不满意时怎么说

- 「H2 不对，默认立场是乙方」（改假设）
- 「环节 3 漏掉了验收风险」（改某环节）
- 「输出改成只要报告和 JSON」（改交付）
