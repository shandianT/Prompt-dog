# 变更日志

## v1.2（2026-09-07）

- 立场缺省不再阻塞：能从委托方推断就推断并标注，推断不了才出一题选择卡（默认中立）
- 写入 `输出/` 视为本地落盘，不需确认；人工确认只保留在对外发送/定稿/签署建议前
- 闭环修正：每轮只重跑被点名环节及下游；同一环节最多退回 1 次；止损线从「连续 2 轮不增加」（在最大 3 轮下永远触发不了）改为「一轮不增加」
- 止损时照常交付三件套 + 卡点报告；单人设版默认连续执行到交付，不再每阶段等「继续」
- 环节 1 缺页码时改用条款/段落序号定位，不中断
- 审查逻辑（环节 1–7、红线、交付格式）不变，本次升级无需回归
