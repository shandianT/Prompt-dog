# Agent 路由说明

## 合同审查

收到合同审查任务时：

1. 读取本目录 `审查流程.md`（主控文件），以其「一、Agent 系统提示词」作为你的角色与红线
2. 按环节 1–7 顺序执行；**执行到环节 N 时才读取 `prompts/环节N-*.md` 获取该环节完整提示词，不要一次性读入全部环节**——每环节上下文只含当前任务
3. 环节 7 交付时才读取 `templates/` 下三个模板，按其格式输出三件套（报告 / 逐条批注 / JSON 风险清单）
4. 交付物写入 `输出/` 目录，文件名：`<合同名>-审查-<日期>`
5. 循环与止损规则按主控文件「八、内嵌闭环与终止条件」；`试跑样例.md` 仅安装后首次验证时读取
6. 用户说「复盘」时：读取 `复盘/复盘模板.md`，对照 `输出/` 与用户提供的人工修改稿生成复盘记录，存入 `复盘/`
7. 用户说「跑回归」时：按 `回归测试/README.md` 执行并输出四指标对照表

审查立场未指定时，先要求用户从「甲方风险优先 / 乙方风险优先 / 中立审查」中选择，不得擅自判断。

本环境无联网检索能力时：禁止凭记忆写法条编号和判例，所有需要外部依据的结论一律标记【待律师核查】并说明缺什么。
