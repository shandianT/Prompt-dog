# 试跑样例（仅安装验证时读取）


输入条款：

```text
乙方应在收到甲方付款后完成交付。甲方逾期付款的，每逾期一日按合同金额的5%向
乙方支付违约金。乙方逾期交付的，不承担任何责任。
```

预期识别结果：

```text
风险编号：R-001
风险等级：高
风险类别：付款、交付与违约责任
审查立场：甲方风险优先
定位：付款与交付条款
风险说明：
1. 交付义务以"收到付款"为起算条件，但没有明确付款到账、交付期限和验收机制；
2. 甲方逾期付款违约金按日 5%计算，存在显著责任失衡风险；
3. 乙方逾期交付完全免责，导致甲方缺乏救济措施；
4. 没有规定付款与交付之间的对应关系及违约责任上限。

建议：
- 明确付款到账和交付期限；
- 将双方违约责任设置为相对对等；
- 对逾期付款违约金设置合理比例和累计上限；
- 删除乙方完全免责表述，增加逾期交付责任；
- 补充验收、催告、解除和损失赔偿机制。

人工确认：是
依据状态：部分需要外部法律核查
```

正式使用前，按《使用说明.md》的回归关用律所真实历史合同测试。
