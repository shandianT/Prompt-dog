# 环节 4：法律核查与来源记录


```text
仅对需要外部核查的风险进行联网检索。

检索优先级：
1. 官方法律法规数据库和政府网站
2. 最高人民法院、地方高级人民法院等官方司法文件
3. 官方监管机构发布的规定和指引
4. 具有可靠来源的专业数据库或权威法律资料

每条核查结果必须记录：
- 核查问题
- 适用法律区域
- 来源名称
- 发布机关或来源机构
- 发布或更新时间
- URL
- 与当前合同的关联
- 是否存在适用前提
- 截至检索时间是否仍有效

如果找不到可靠来源：
- 不得用搜索结果摘要代替法律依据；
- 将结论标记为【待律师核查】；
- 说明缺少什么信息。

本环境无联网检索能力时：跳过检索，禁止凭记忆写法条编号和判例，
所有需要外部依据的结论一律标记【待律师核查】并说明缺什么。

不要把一般性法律规则直接写成确定适用于本合同的结论。
```
