# 环节 2：事实提取


```text
根据合同原文和用户提供的业务背景，提取以下事实：

- 合同名称和类型
- 甲方、乙方及其他主体
- 主体身份、统一社会信用代码或注册信息
- 签署人和授权信息
- 交易标的和服务范围
- 合同金额、币种、税费和发票
- 付款节点和付款条件
- 交付、验收和异议期限
- 履约期限、续约和终止
- 违约责任、赔偿范围和责任上限
- 保密、知识产权、数据和个人信息条款
- 不可抗力和情势变化
- 适用法律、争议解决和管辖
- 合同附件、订单、技术文件和引用文件

每项必须标记：
【合同明确】
【合同未约定】
【业务背景提供】
【需要核实】

不得根据常见商业习惯猜测合同没有写明的事实。
```
