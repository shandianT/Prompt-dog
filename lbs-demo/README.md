# LBS 史维莎 · 销售管理小程序 Demo

纯前端、无后端、模拟数据的可点击演示，以微信小程序界面在浏览器中呈现。用于 2026-09-07 LBS 需求沟通后的周四评审，对齐《LBS 史维莎销售管理小程序 PRD v0.1》包 A / P0 闭环，并预览包 B / P1 能力边界。

- 在线入口：`/lbs-demo`（Vercel 部署后）或本地直接打开 `index.html`
- 需求梳理：[`requirements.html`](requirements.html)（源文件 [`需求梳理.md`](需求梳理.md)）
- 演示日期固定为 2026-09-07（周一）；门店、联系人、金额均为虚构样本

## 演示路径（对齐 PRD 7.1 一马路 / 丙店故事）

1. 今日工作台：今日约访、超期回访、待确认记录、服务风险提醒
2. 街道模式「一马路」：甲店服务中 + 未结客诉、乙店两天前已拜访（重复拜访提示不阻断）、丙店今日约访；无权门店只给最小避重提示
3. 丙店客户详情 → 拍门头（OCR 候选，不按名称自动合并）+ 风险点位照片 + 口述转写
4. 待确认事实：不填造老板姓名、"疑似鼠迹"不改成确认虫害、承诺/金额/日期单独确认；本地草稿 → 上传中 → AI 处理中 → 待确认 → 本系统已保存 → CRM 同步成功
5. 商机推进卡：正式阶段 / 258 分层与 AI 建议分离；依据、缺失项、置信度、规则版本；一次确认阶段 + 分层 + 任务草稿；拒绝需说明原因；没有任何按钮能置为"已赢单"
6. 方案工作台：已审核餐饮单店模板 → 输入确认 → 照片位置 → 生成 → 预览；价格处显示"报价待审批"；生成 / 导出 / 人工标记发送分别记录
7. 回访任务：客户约定日期 > 已接受任务 > 规则周期（演示规则）；同商机同周期去重；改期保留原因
8. 工作助手：只引用已审核发布的知识；未收录问题"待核实"并可转技术协助；主管问数带口径、样本量、更新时间，金额未接入不推算
9. 主管团队工作台：卡点、未跟进、待复核、趋势，下钻到客户与证据
10. P1 预览：按类别报价（缺参数不出价）、承诺—方案—报价—合同一致性（重要差异阻断提交）、合同一键生成与审批接入、履约 / 回款 / 续约摘要、KA 经营卡、虫害拍照辅助识别

左侧「演示导览」面板可切换角色（地推 / KA / 主管）、按步骤跳转、查看当前页面对应的 PRD 条目与业务规则、执行演示动作（模拟断网、AI 失败、CRM 超时等）、重置数据。
