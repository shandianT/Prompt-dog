## 一名地推销售的一天 · 十分钟八步（左侧导览可一键跳转）

1. 授权与出发：录音 / 定位 / 相机三项用途明示；首页今日路线、待办、回访提醒一屏
2. 进入街道 · 扫街辅助：一马路 新开 / 合作 / 待回访三组，展示项按地推部配置、不开放个人自定义
3. 到店 · 打点与拍门头建档：定位与时间戳自动带入；OCR 带置信度；工商匹配与去重由人选择、不自动合并
4. 拜访后 · 说一句留痕：实时转写、热词高亮、识别中断不丢内容、弱网缓存待同步、首次拜访追加 4 项
5. 只改错的字段 · 两道闸门：16 + 4 字段带置信度与原文定位；质量评分 58 / 60 未过 → 修改下一步、补一句客户原话 → 71 通过；下一步硬校验；归档后选商机
6. 分层与回访提醒：四象限 A/B/C/D 由规则计算（阈值为演示值），回访周期自动生成，延期原因必填
7. 现场答疑 · 识虫与知识库：答案带出处，未命中不编答案回流管理员；拍照识虫给种类 / 习性 / 危害 / 处置
8. 有意向 · GTM 助手：三类模版（方案 / 报价单 / 保险单）AI 推荐，六段方案 + 报价单即时重算，折扣超阈值进价格审批，分享预览
9. 晚上收工 · 今日回顾：四个数字 + AI 即时总结，已打点未留痕点名，明日路线建议
10. 主管手机端：留痕率 / 已留痕 / 平均分 / 待审批，一键催办 / 发起辅导 / 下发客户 / 创建任务，团队即时总结，数据咨询
11. 任务闭环：接受 / 拒绝附意见、标记完成、延期原因必填，结果推回发起人
12. 客户 360（手机端）：基本信息、拜访时间线、商机、方案与报价、回访与待办

左侧「演示导览」可切换账号、按步骤跳转、查看当前页对应的 deck 页与规则、执行演示动作（模拟识别中断、弱网、门槛拖到 85 等）、重置数据。
