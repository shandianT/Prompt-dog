# 复盘（仓库级）

这里是 PromptDog 本身的复盘日志，不是某只工作狗的。规则与 `references/run-loop.md` 的「复盘两级制」相同：

- **日志**：一天一份 `YYYY-MM-DD-<主题>.md`，只追加不改写。记讨论脉络、结论、没定的事、产物链接。趁热写，写得快比写得全重要。
- **抬升**：日志里「下次做别的事还用得上」的规律，抬到它会被读到的位置——改行为的进 `SKILL.md` / `references/`，定方向的进 `design/`，对外可见的进 `CHANGELOG.md`。抬升后在日志里标一行「已抬升 → 文件」。

判断沉淀对不对只有一条：明天新开会话，把仓库丢给 agent，它不看聊天记录就能接着做。
